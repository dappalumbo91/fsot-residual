## FSPACK

`fspack.py` is the packer. It reads pin AEB2AD from `vendor/fsot_compute.py` and refuses to run if that hash moves. A lossless member restores byte for byte. A picture or audio member keeps a closed-loop prediction and a step `Q` that is declared before the file is scored. The POOF/SUCTION fraction is stored in the header and is not used as the compression ratio.

```text
python fspack.py selftest
python fspack.py pack INPUT -o OUT.fsp
python fspack.py unpack OUT.fsp -o RESTORED
python fspack.py bench
```

`pack` takes a file or a folder. `bench` scores the Seagate sample clip and `cries_in_the_beat.mp3`. The measured table is [results/REPORT.md](results/REPORT.md). On the first run, 24 decoded frames came back exact at Q=1, and Q=16 is where the picture breaks into blocks. An mpeg4 or mp3 container did not shrink. Those bytes are already coded.

## Build

Python is the pass language. The coders that write the lossy bytes are C. On this machine the compiler is clang.

```text
clang -O2 -o gauge_rans.exe gauge_rans.c
clang -O2 -o fold_range.exe fold_range.c
```

`gauge_rans.c` is the static order-0 rANS used from the gauge pass onward. `fold_range.c` is the adaptive range coder. Counts start at 1. fold1 through fold4 and the formula pass call that executable. The bench needs Python 3, numpy, and ffmpeg. The engine is the sibling checkout `FSOT-2.1-Lean/vendor/fsot_compute.py` at pin AEB2AD. That file is not copied into this repository.

## Working rules

- Name the object before scoring it: the bit string, the symbol, the scalar, or the gauge. A codon restored as an amino acid is a different object from the codon itself.
- The decoder already holds the engine. The compressed state stores the index into that library plus the residual the library does not fix.
- Write the residual floor first. A pass is a residual inside that floor. Moving the floor after the score is a different experiment.
- A message the library does not contain compresses at its own entropy. A result below that entropy on an incompressible control means the code is wrong.
- Zero arbitrary free parameters. Quantities the law already derives may be used. A coefficient fitted to land nearer the original stays out.
- Ledger A, Ledger B, and Ledger C stay separate. This folder does not retune pins, `vendor/fsot_compute.py`, hashed freezes, or the 91-row precision gate.
